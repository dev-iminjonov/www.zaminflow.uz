# Defect Report: QA-006

**Title:** Missing OWASP Security Headers (`X-Frame-Options`, `CSP`) and `X-Powered-By` Disclosure  
**Defect Type:** Security Defect / Infrastructure Hardening (OWASP ASVS Section 14)  
**Severity:** S3 Minor  
**Priority:** P1  
**Status:** New  
**Area:** HTTP Response Headers / Caddy & Next.js  
**URL:** `http://localhost:3000/`  

---

### Preconditions
Web client makes an HTTP GET request to `http://localhost:3000/`.

---

### Steps to Reproduce
1. Execute cURL or inspect response headers:
   ```bash
   curl.exe -I http://localhost:3000/
   ```
2. Inspect the returned HTTP headers.

---

### Expected Result (OWASP ASVS v4.0.3 Sec 14.4)
The server should respond with industry-standard defensive security headers:
- `X-Frame-Options: DENY` (prevents clickjacking attacks)
- `X-Content-Type-Options: nosniff` (prevents MIME confusion)
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Content-Security-Policy: default-src 'self' ...`
- No `X-Powered-By` header revealing backend technology.

---

### Actual Result
Headers returned:
```http
Vary: rsc, next-router-state-tree, ...
X-Powered-By: Next.js
Cache-Control: s-maxage=31536000
Content-Type: text/html; charset=utf-8
```
* `X-Frame-Options` is **missing** (app can be framed in malicious iframes).
* `X-Content-Type-Options` is **missing**.
* `Content-Security-Policy` is **missing**.
* `X-Powered-By: Next.js` is **actively disclosed**.

---

### Suggested Fix
In [`frontend/next.config.mjs`](file:///c:/Users/Muhammad%20Aziz/Downloads/www.zaminflow.uz/frontend/next.config.mjs):
```javascript
const nextConfig = {
  poweredByHeader: false,
  async headers() {
    return [
      {
        source: "/(.*)",
        headers: [
          { key: "X-Frame-Options", value: "DENY" },
          { key: "X-Content-Type-Options", value: "nosniff" },
          { key: "Referrer-Policy", value: "strict-origin-when-cross-origin" },
        ],
      },
    ];
  },
};
```

---

### Acceptance Criteria for Re-Test
1. `curl.exe -I http://localhost:3000/` contains `X-Frame-Options: DENY` and `X-Content-Type-Options: nosniff`.
2. `X-Powered-By` header is absent.
