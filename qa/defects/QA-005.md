# Defect Report: QA-005

**Title:** Social Media Links in Team Carousel Fail WCAG 2.5.8 Minimum Touch Target Size (16px $\times$ 16px)  
**Defect Type:** Accessibility & Mobile Usability Defect  
**Severity:** S3 Minor  
**Priority:** P2  
**Status:** New  
**Area:** Public Landing Page / Team Section  
**Component:** [`frontend/src/components/OurTeamCarousel.tsx`](file:///c:/Users/Muhammad%20Aziz/Downloads/www.zaminflow.uz/frontend/src/components/OurTeamCarousel.tsx#L178)  

---

### Preconditions
User navigates to `http://localhost:3000/#team` on a mobile or touch device.

---

### Steps to Reproduce
1. Scroll down to the "Our Team" carousel.
2. Inspect the LinkedIn, GitHub, and Instagram social links below each member card.
3. Measure the computed CSS bounding box of the `<a>` element:
   - Elements use classes `text-[#64748B] hover:text-[#00C853]` with an inner `<svg className="w-4 h-4 fill-current">` and no padding.
   - Computed bounding box: **16px $\times$ 16px**.

---

### Expected Result (WCAG 2.2 SC 2.5.8 Target Size Minimum)
Interactive touch targets must have an area of at least **24 $\times$ 24 CSS pixels** (with 44 $\times$ 44 recommended for AAA / mobile ergonomics) to avoid accidental taps on adjacent links.

---

### Actual Result
The bounding box is only 16px $\times$ 16px. Adjacent icons (LinkedIn, GitHub, Instagram) are placed only 16px apart (`gap-4`), leading to frequent mis-taps on mobile touchscreens.

---

### Suggested Fix
Add padding to each anchor link to expand the interactive hit-box to at least 44 $\times$ 44 pixels:
```diff
--- a/frontend/src/components/OurTeamCarousel.tsx
+++ b/frontend/src/components/OurTeamCarousel.tsx
@@ -176,3 +176,3 @@
-                    className="text-[#64748B] dark:text-[#94A3B8] hover:text-[#00C853] dark:hover:text-[#00C853] transition-all duration-200 transform hover:scale-110"
+                    className="w-10 h-10 rounded-full flex items-center justify-center text-[#64748B] dark:text-[#94A3B8] hover:text-[#087a3c] hover:bg-black/5 dark:hover:bg-white/5 transition-all duration-200"
```

---

### Acceptance Criteria for Re-Test
1. Computed bounding box of each social link $\ge 40 \times 40$ px.
2. Lighthouse Accessibility score reflects no target-size warnings.
