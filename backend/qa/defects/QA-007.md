# Defect Report: QA-007

**Title:** Driver Dashboard Desktop Navigation Bar Wraps and Breaks on Mobile Viewports (360–390px)  
**Defect Type:** Responsive Layout Defect / Mobile Ergonomics  
**Severity:** S3 Minor  
**Priority:** P2  
**Status:** New  
**Area:** Role Dashboards / Driver  
**Route:** `/dashboard/driver`  
**Component:** [`frontend/src/components/dashboard/DriverOverview.tsx`](file:///c:/Users/Muhammad%20Aziz/Downloads/www.zaminflow.uz/frontend/src/components/dashboard/DriverOverview.tsx#L84)  

---

### Preconditions
User is logged in as a Driver (`driver@zaminflow.uz`). Viewport is set to 390px $\times$ 844px (iPhone 13/14) or 360px $\times$ 800px (Samsung Galaxy A-series).

---

### Steps to Reproduce
1. Log in to `http://localhost:3000/signin` as Driver.
2. In Chrome DevTools, toggle Device Toolbar and select **iPhone 12 Pro (390px)**.
3. Observe the floating pill navigation bar at the top of `/dashboard/driver`.

---

### Expected Result
On mobile devices, navigation should either collapse into an accessible drawer/menu, scroll horizontally as a pill carousel, or display a fixed bottom navigation bar suitable for single-thumb truck driving operations.

---

### Actual Result
The navigation bar uses `flex-wrap` with rigid padding (`px-8 py-3.5`) and `gap-7`:
```tsx
<div className="flex flex-wrap items-center gap-7 text-[15px] font-semibold">
  <Link ...>Overview</Link>
  <Link ...>My trips</Link>
  <Link ...>Route</Link>
  <Link ...>History</Link>
</div>
```
On screens $\le 390\text{px}$, the 4 text links wrap across 3 vertical tiers inside the pill, expanding the nav height from 60px to over 160px and pushing the driver's next pickup card below the immediate fold.

---

### Suggested Fix
On mobile screens (`sm:hidden`), apply a horizontally scrollable container with smaller font (`text-xs`) or compact icon tabs:
```diff
--- a/frontend/src/components/dashboard/DriverOverview.tsx
+++ b/frontend/src/components/dashboard/DriverOverview.tsx
@@ -84,3 +84,3 @@
-        <nav className="bg-white rounded-[40px] px-8 py-3.5 flex flex-wrap items-center justify-between gap-4 shadow-[0_10px_40px_rgba(20,80,60,0.08)]">
+        <nav className="bg-white rounded-[28px] sm:rounded-[40px] px-4 sm:px-8 py-3 flex flex-wrap items-center justify-between gap-2 sm:gap-4 shadow-[0_10px_40px_rgba(20,80,60,0.08)]">
@@ -88,3 +88,3 @@
-          <div className="flex flex-wrap items-center gap-7 text-[15px] font-semibold">
+          <div className="flex items-center gap-3 sm:gap-7 text-xs sm:text-[15px] font-semibold overflow-x-auto max-w-full pb-1 sm:pb-0">
```

---

### Acceptance Criteria for Re-Test
1. Nav height on 390px viewport does not exceed 70px.
2. No awkward multi-line text wrapping of navigation links.
